## selection_focus
Select the "Features" hub and each feature or capability page (e.g. /features/*), plus feature sections of solution pages. This is the core chapter — prefer broad coverage of all feature pages.

## synthesis_instructions
Give a thorough, organized tour of the product's features and capabilities, grouped by functional area or the site's own feature categories. Use subsections or a table (Feature / What it does / Notes) with a few factual sentences each. Describe what each feature actually does and when it is useful, not just its name. Keep descriptions concrete and free of promotional adjectives. Do not invent features or capabilities beyond the pages; if a feature is only named, list it plainly. Omit the chapter only if the site documents no features (unusual for this type).
